# VMI — Music Intelligence Representation

VMI is an independent music intelligence system.

Its purpose is to represent audio with maximal recoverable musical,
technical and production information.

VMI is designed for:

- AI music analysis
- AI music generation
- reconstruction research
- MIDI generation
- MusicXML generation
- DAW workflows
- music production analysis
- mobile inference
- VELDRA integration

## Core philosophy

Natural-language descriptions are lossy.

VMI therefore uses structured representations containing:

- signal
- spectral
- rhythm
- harmony
- melody
- timbre
- spatial
- performance
- arrangement
- production
- semantic
- reconstruction information

Each feature should preserve provenance and confidence where applicable.

## Development principle

VMI consists of multiple layers:

1. deterministic audio analysis
2. specialized audio models
3. structured representation
4. language-model reasoning
5. reconstruction
6. evaluation
7. optimization

Training happens in the cloud.

Inference is intended to eventually support Android devices.

## Initial genre priority

VMI remains genre-agnostic.

Initial optimization focus:

- electronic music
- trance
- progressive trance
- psytrance
- progressive psytrance
- Goa trance
- melodic trance
- techno
- house
- pop

## Observatory

VMI Observatory is the real-time visualization system for:

- analysis

- inference

Observatory visualizations must represent real telemetry.
